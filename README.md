# Orbit — Space Explorer Quiz

Orbit is a small, responsive space-trivia quiz. Answer multiple-choice questions, see whether each answer is correct, and get a final score. The interface supports light and dark color schemes and respects reduced-motion preferences.

## Run locally

No build step, dependencies, or server are required. Open `index.html` in a web browser to play.

## Deployment

The site is deployed to GitHub Pages by the **Deploy to GitHub Pages** GitHub Actions workflow whenever changes are pushed to `main`. You can also start a deployment manually from the repository's Actions tab.
